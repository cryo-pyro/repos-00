II — The Mathematics

Formalizing Clinical Error as Optimization Failure

Classical SGD requires noise ε—Dionysian exploration—to escape local minima. But the temperature parameter must be calibrated to the gradient. When the gradient in a dimension is zero, injecting variance into that dimension is not exploration—it is error.

The State Space

# Patient biological state at time t
xt = [It, Gt, Pt, Mt]

# Dimensions:
I ∈ [0,1] # Gastric Inflammation
G ∈ [0,1] # Lower GI Pathology
P ∈ [0,1] # Pain Signal
M ∈ [0,1] # Mucosal Integrity (higher = healthier)

# Transition dynamics (non-stationary!)
xt+1 = f(xt, ut) + ωt # ω ~ N(0, σ²)

Three Hidden Loss Functions

Most clinical over-testing is not noise—it is gradient descent on a different loss function. Separating these is the conceptual breakthrough that makes the twin operational rather than metaphorical.

Lb
Biological Loss
Pain · Inflammation · Mucosal deficit. The only loss function that matters for the patient's body.
Ls
System Loss
Liability, throughput, billing. When negatively weighted, high-cost tests become the global minimum for the institution.
Lc
Cognitive Loss
Uncertainty discomfort. Clinicians over-test to reduce their own epistemic entropy, not the patient's biological loss.
# What actually gets optimized:
Ltotal = Lb + λ₁·Ls + λ₂·Lc

# Patient-set weights via API (Ukubona Twin):
α = 0.20 # system/economic weight
β = 0.10 # entropy/uncertainty weight

# Measurable uncertainty proxy (replaces vague "noise"):
H(p) = -∫ p(x) log p(x) dx # posterior entropy

# Optimal next test = maximize value of information:
a* = argmaxa [H(p) − E[H(p′|a,y)]] / cost(a)

IV — The Digital Twin

Pheromone Infrastructure & State Continuity

Ant colony optimization leaves externalized memory in the environment. Medicine currently keeps memory fragmented across patient recall, physician notes, and institutional silos. The Ukubona Digital Twin proposes a persistent probabilistic memory field around the patient.

This is not digitizing forms. This is digitizing trajectory.

01
Transparency / Witness Mode
Patients see the math: posterior probabilities, entropy values, VoI per proposed test. Decisions are demystified. The algorithm is visible.
02
Personalization / Pheromone Control
Weights in L_total are patient-tunable. Risk-averse? Higher exploration. Cost-sensitive? Reduce system weight. Local priors (geography, demographics) auto-adjusted.
03
Non-stationarity Handling
The twin continuously re-estimates the landscape via online learning. Treatment changes physiology, which changes the terrain being measured. Static risk scores fail chronically ill patients for exactly this reason.
04
Multi-Loss Detection
The twin models which loss function is being optimized at each step. Hidden L_s (system) signals are flagged. Patients learn to recognize when the system is descending on its own gradient, not theirs.

V — Replicate

The Toy Twin — Python Source

Full simulation code. Dependencies: numpy · scipy · matplotlib. Run with python ukubona_toy_twin.py. Extend by replacing the toy ODE with real GI physiology parameters from literature.

ukubona_toy_twin.py
"""
Ukubona LLC — Gastric Toy Twin Simulation
==========================================
State space:   x = [Gastric Inflammation, Lower GI, Pain, Mucosal Integrity]
Loss:          L_total = L_b + α·L_s + β·H(posterior)
Horizon:       12 time steps  |  σ_process = 0.025
"""

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.gridspec import GridSpec
from scipy.stats import entropy as scipy_entropy

np.random.seed(42)

# ── STATE SPACE ──────────────────────────────────────────
INITIAL_STATE = np.array([0.82, 0.04, 0.75, 0.38])

# ── LOSS FUNCTIONS ───────────────────────────────────────
ALPHA, BETA = 0.20, 0.10

def L_bio(state):
    I, G, P, M = state
    return 0.40 * I + 0.40 * P + 0.20 * (1 - M)

def H_state(state):
    probs = np.abs(state) / (np.sum(np.abs(state)) + 1e-9)
    return float(scipy_entropy(probs + 1e-9))

def L_total(state, cost):
    return L_bio(state) + ALPHA * cost + BETA * H_state(state)

# ── ACTIONS ──────────────────────────────────────────────
ACTIONS = {
    "PPI Trial":        {"cost": 0.05, "delta": np.array([-0.30, 0.00, -0.38, +0.22]), "voi": 0.35},
    "Endoscopy":         {"cost": 0.40, "delta": np.array([-0.05, 0.00, -0.05, +0.05]), "voi": 0.88},
    "Colonoscopy":       {"cost": 0.80, "delta": np.array([0.00,  0.00, 0.00,  -0.03]), "voi": 0.02},
    "Profit-Optimised": {"cost": 0.80, "delta": np.array([0.00,  0.00, 0.00,  -0.03]), "voi": 0.02},
}

# ── SIMULATION ───────────────────────────────────────────
HORIZON, SIGMA = 12, 0.025

def simulate_path(initial_state, action_key, horizon=HORIZON):
    action = ACTIONS[action_key]
    state  = initial_state.copy()
    losses, lb_arr, H_arr, states = [L_total(state, 0)], [L_bio(state)], [H_state(state)], [state.copy()]
    for t in range(horizon):
        decay = np.exp(-0.25 * t)
        cost  = action["cost"] if t == 0 else 0.0
        state = np.clip(state + action["delta"] * decay + np.random.normal(0, SIGMA, 4), 0, 1)
        losses.append(L_total(state, cost)); lb_arr.append(L_bio(state)); H_arr.append(H_state(state)); states.append(state.copy())
    return np.array(losses), np.array(lb_arr), np.array(H_arr), np.array(states)

paths = {k: simulate_path(INITIAL_STATE, k) for k in ACTIONS}

# ── PLOT (abbreviated — see full file for 7-panel figure) ─
T = np.arange(HORIZON + 1)
PALETTE = {"PPI Trial": "#00C9A7", "Endoscopy": "#4E9AF1",
           "Colonoscopy": "#FF6B6B", "Profit-Optimised": "#FF9F43"}

fig, ax = plt.subplots(figsize=(10, 5), facecolor="#0D1117")
ax.set_facecolor("#161B22")
for k, (losses, _, _, _) in paths.items():
    ax.plot(T, losses, color=PALETTE[k], label=k, lw=2)
ax.legend(); ax.set_title("Ukubona Gastric Twin — Loss Trajectories", color="white")
plt.tight_layout()
plt.savefig("ukubona_toy_twin.png", dpi=150, bbox_inches="tight")
print("Simulation complete.")
