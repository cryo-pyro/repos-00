Phase Two · Escape The Ridge: not a gate, a geometry

The ridge is the energy barrier between two attractor basins. It is not a gate — a gate is binary and instantaneous. A ridge is geometric: it has height, width, curvature. You can approach it slowly for decades and cross it in a moment.

This distinction matters clinically because it changes what the digital twin watches for. A gate model asks: did the signal cross threshold? A ridge model asks: how close is the system to the crest, and how fast is it approaching?

The ridge crest is the point where ∇L reverses sign — uphill on one side, downhill on the other. Before the crest: no visible gradient, compensated homeostasis, "normal labs." At the crest: the phase transition, the cry, the acute presentation. After the crest: gradient descent becomes possible for the first time.

Ridge Crossing Condition \[ \text{Escape iff: } \epsilon_t > \Delta\mathcal{L}_{ridge} = \mathcal{L}(\theta_{ridge}) - \mathcal{L}(\theta^*_{basin}) \] \[ \text{Pre-ridge: } \nabla\mathcal{L} \approx 0 \text{ (gradient invisible to clinician)} \] \[ \text{Post-ridge: } \nabla\mathcal{L} \gg 0 \text{ (gradient now actionable)} \]

The twin's pre-ridge job is to estimate ΔL_ridge — the remaining reserve — from trajectory data. Decades of calcium extraction, declining renal hydroxylase, falling magnesium. The ridge is approaching. The labs still look normal. The twin knows the distance is shrinking.

Why "ridge" not "gate" A gate is crossed once, irreversibly, like a switch. A ridge has curvature — the second derivative of L tells you whether the region near the crest is broad and gradual or sharp and catastrophic. High curvature = sudden presentation. Low curvature = gradual symptom onset. Same ridge, different geometry, different clinical experience.
Ridge Geometry In the loss landscape, the ridge is a saddle point — a maximum in one direction (the direction of escape) and a minimum in the orthogonal direction.

The Hessian H = ∂²L/∂θ² determines ridge sharpness. Negative eigenvalue in the escape direction = confirmed ridge, not plateau.

Clinical proxy: Abruptness of symptom onset ↔ curvature of ridge. Sudden cry after apparent wellness = sharp ridge, rapidly approached.

Phase Three · Descent Four fates of the gradient once visible

Post-ridge, the gradient is real. Now everything depends on η — the learning rate, the intervention calibration. The gradient can be:

GRADIENT FATE — PSEUDOCODE # Post-ridge descent options # θ_t = current patient state, ∇L = visible gradient def descend(θ_t, ∇L, η, intervention): if intervention == "correct_cause": # STEEPENED — gradient accelerates toward minimum θ_next = θ_t - η_large * ∇L # e.g. VitD loading + ferritin repletion → PTH quiets, # BAP falls, neuromuscular misfiring stops elif intervention == "partial_correct": # FLATTENED — gradient exists but descent slows θ_next = θ_t - η_small * ∇L # e.g. VitD repleted but renal 1α-hydroxylase limits # active conversion → storage D up, symptoms persist elif intervention == "wrong_axis": # CANCELLED on that axis — but new gradient revealed θ_next = θ_t - η * ∇L_RLS # ferritin → dopamine axis # independent of mineral axis, cancels that gradient # separately. Two gradients, two cancellations required. elif intervention == "twin_monitored": # PREVENTED — twin tracks approach to next ridge ΔL_ridge_remaining = twin.estimate_reserve(θ_t) if ΔL_ridge_remaining < THRESHOLD_WARN: alert("Ridge approach detected. Intervene now.") # Prevents escape from occurring at all # Basin walls maintained through abundance, not depletion return θ_next
Learning Rate Calibration — the η problem \[ \eta_{optimal} = \arg\min_\eta \mathbb{E}\bigl[\mathcal{L}(\theta_{t+k})\bigr] \] \[ \text{Overshoot: } \eta \gg \eta_{opt} \Rightarrow \theta \text{ oscillates, misses basin} \] \[ \text{Understep: } \eta \ll \eta_{opt} \Rightarrow \text{descent stalls, symptom persists} \] \[ \text{Wrong axis: } \nabla_\theta\mathcal{L} \perp \nabla_\phi\mathcal{L} \Rightarrow \text{two separate descents required} \]

Phase Four · Sample Low-ε probing: VoI / cost is the only justification

Sampling is not escape. The temperatures are different. Escape requires enough ε to clear the ridge wall — externally driven, often involuntary. Sampling is deliberate, low-amplitude probing from within the descent, near a candidate minimum.

VALUE OF INFORMATION — TEST SELECTION # Should we order this test? def should_sample(test, posterior_p, current_H): VoI = current_H - expected_H_after_test(test, posterior_p) cost = test.invasiveness + test.financial + test.patient_burden ratio = VoI / cost # The colonoscopy in Case I: # p(lower_GI_pathology | no_bowel_sx) ≈ 0.03 # VoI ≈ 0.02 bits (posterior already near-flat) # cost = high (invasive, expensive, traumatic) # ratio → 0.02 / HIGH ≈ 0 → DO NOT SAMPLE # VitD + ferritin in Case II: # H(posterior) HIGH (mechanism unknown) # VoI ≈ large (two missing variables explain everything) # cost = LOW (blood draw) # ratio → LARGE / LOW → SAMPLE IMMEDIATELY return ratio > THRESHOLD_WORTH_IT

It was actually descent on L_s (liability minimization) disguised as L_b (biological) exploration. The VoI was near zero. The cost was high. A rational sampler would have rejected it. The twin would have shown the math.

Phase Five · Integrate The pheromone update. Then Basin again.

Integration is what separates a clinical episode from a trajectory. Every descent, every sample, every basin reached — if integrated into the twin — becomes prior knowledge that reshapes the next cycle's landscape model.

BAYESIAN TWIN UPDATE — POSTERIOR → NEW PRIOR # After each BEDSI cycle, update the twin's model def integrate(twin, trajectory, outcome): # Update posterior over patient state twin.posterior = bayesian_update( prior = twin.prior, evidence = trajectory.observations, model = twin.dynamics_model ) # Update landscape model — non-stationary terrain twin.L_estimate = online_learn( twin.L_estimate, new_data = trajectory.state_transitions ) # Update ridge proximity estimate twin.reserve_estimate = estimate_basin_wall( twin.posterior, twin.L_estimate ) # New basin IS new prior for next cycle twin.prior = twin.posterior # The pheromone trail is now richer # Next clinician inherits the map, not a blank chart return twin # → B (next basin) → cycle restarts

The cycle is not a loop that closes. It is a spiral. Each iteration of BEDSI lands in a deeper, better-mapped basin, with a richer posterior and a more accurate landscape model. The twin accumulates what individuals forget. The colony benefits from every scout that returned.

The patient is never done. They are always in some phase. The twin knows which one.

Upper endoscopy: correct. Apollonian descent along the visible gradient. Confirms antral gastritis. Gradient direction is known. PPI prescribed. η is appropriate. The loss function is decreasing. This descent phase executed correctly.

Colonoscopy ordered — critical error here. VoI = H(posterior_lower) − E[H(posterior_lower | colonoscopy)] ≈ 0.02 bits. p(lower pathology | no bowel symptoms) ≈ 0.03. Case II The Compensated Gradient — Decades of mineral debt, suddenly visible
B
BASIN
An elderly multiparous woman of African ancestry in apparent metabolic stability. Calcium 2.51 mmol/L — normal. PTH 40 pg/mL — mid-range. BAP 16 µg/L — active but within reference. This basin is not low-energy health. It is defended homeostasis. The basin floor is rising. The walls are thinning. The twin would see it. The chart does not.

ESCAPE
Paroxysmal, rest-triggered, cry-level limb pain. The ridge is crossed. ε_escape came from decades of cumulative mineral debt — not an acute event. The presentation feels sudden because ridge curvature was high: a sharp crest, approached gradually, crossed quickly. NSAID failure removes prostaglandin-mediated pathways from the graph. Rest-trigger with activity suppression eliminates most structural and inflammatory differentials. The gradient is now visible. The question is: in which coordinate?

DESCENT
Two candidate descent axes, both real, potentially independent: (1) Mineral axis: vitamin D deficiency → secondary hyperparathyroidism (PTH should be elevated but Mg deficit suppresses it — doubly compromised) → osteomalacic muscle irritability. (2) Dopaminergic axis: ferritin < 75 µg/L → iron deficiency in basal ganglia → RLS misfire at rest. Optimal η: high-dose cholecalciferol loading + ferritin repletion. Wrong η: NSAIDs (already failed), or imaging before biochemistry is complete.
